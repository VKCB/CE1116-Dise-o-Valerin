## 📚 Idea/Concepto

Una Virtual Private Cloud es una sección lógicamente aislada dentro del cloud público que utiliza redes definidas por software (SDN) para crear una red virtual sobre infraestructura compartida. Permite definir rangos CIDR, subredes, tablas de enrutamiento, gateways, seguridad por capas (NACLs y Security Groups) y conectividad híbrida mediante VPN o peering entre VPC.

## 📌 Puntos Claves

- Aislamiento lógico
- SDN
- CIDR y subredes
- Seguridad por capas
- Conectividad híbrida
